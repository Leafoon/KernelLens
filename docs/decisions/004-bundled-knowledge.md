# ADR 004：KernelLens 与知识包一起分发

状态：已实现并完成独立安装验收。用户要求把 KernelLens 和知识包放在同一个项目，暂不实现版本选择、远程下载或更新服务。

## 输入与输出

维护者使用已构建、校验通过的本地 TileLang 知识库，导出到 `src/kernellens/data/tilelang/`。普通用户下载 KernelLens 项目或安装 wheel 后，默认加载这个随包目录。

知识包包含 SQLite 索引（内含完整知识正文、参数、示例与关系）、manifest、README 和上游许可文件。不重复分发 JSONL/MCP 兼容视图，也不要求用户持有 TileLang 源码、Git 历史或构建依赖。

## 加载与校验

- 默认加载随包知识；显式 `--knowledge`/配置路径可覆盖，`--no-knowledge` 可关闭。
- 随包快照模式校验索引与知识包完整性，阅读 SQLite 内的完整单元，不访问外部源码。保留原始路径、行范围、源码哈希和 commit 作为出处元数据。
- 原有本地源码模式继续检查工作树中的原文件，供维护者抽取和调试。
- 工具证据在快照模式指向实际知识包文件，原始源码位置单独记录，不能制造用户机器上并不存在的文件路径，也不能声称已核对当前工作树。

## 验收

在没有 TileLang 克隆的隔离目录安装构建产物，验证默认加载、离线查询、全文阅读、API 静态检查、Agent 首次请求预检索与 CLI doctor；损坏包仍需报错。本轮不调用付费模型，不执行 GPU，不提交或发布项目。

验证结果：407 项测试通过，随包检索回归 28/28；隔离安装的 28 条查询、全文阅读、API 检查、两次本地替身模型请求与 CLI doctor 通过。验收禁止联网及访问原始源码；没有真实模型或 GPU 调用。
