# 当前能力与验证范围

核对日期：2026-09-13。本文描述当前可运行版本；完整测试和逐步学习材料由维护者在本地保留。

## 已实现

- 全屏终端 TUI 与 `/` 命令联想、逐行 CLI、工作区切换、单次 JSON 调用、会话持久化与恢复。
- 模型驱动的生成、优化和诊断；单步工具执行、预算、错误反馈与交付审核。
- 文件读写、证据编号、Python AST、有限 GEMM shape/dtype 与初始化检查。
- 目标 GPU 输入、缺失询问、会话记忆及检索后端过滤。
- 内置 TileLang 知识快照：4,337 个语义单元、五类 SQLite FTS5 索引和完整正文，约 31 MiB。普通用户无需 TileLang 克隆。
- 用户服务器报告的代码哈希核对，以及满足条件时的样本比较。

## 已验证

维护者的 Python 3.12 / macOS ARM64 环境中，464 项自动测试通过；28 条本地检索回归通过。测试包含 localhost 模型替身、GPU 输入恢复、候选交付门槛和知识包独立性。完整测试与回归数据不随当前仓库分发。仓库内的源码与完整性检查见 [贡献指南](../CONTRIBUTING.md)。

源码包和 wheel 构建通过，安装包包含知识库。早期独立安装验收验证过在禁止访问原 TileLang 源码和网络的环境中检索、阅读和完成替身 Agent 流程。

## 尚未证明

- 没有自动 GPU Runner；候选需要在对应设备上编译、检查数值和测量性能。
- AST、API 关键字和初始化检查都是有限静态检查，不证明完整计算语义或运行正确。
- GPU 型号是用户声明，后端过滤不认证设备、显存或特殊指令能力。
- 28 条检索问题是开发过程中固定并调整的回归集，不是通用准确率或盲测成绩。
- 不宣称已获得 GPU 性能提升，也不提供未经测量的加速倍数。

详细说明见 [Agent 原理](agent-guide.md)、[RAG 原理](tilelang-rag.md)、[工程验证](validation.md) 和 [RAG 验证](rag-validation.md)。
