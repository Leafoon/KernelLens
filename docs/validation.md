## 仓库内可执行的检查

```bash
uv sync --locked
uv run --locked ruff check src scripts
uv run --locked ruff format --check src scripts
uv run --locked python -m kernellens.knowledge validate
uv run --locked python scripts/sync_diagrams.py --check
uv build
```

仓库根目录只分发图源同步脚本。上述命令不调用模型供应商；首次安装与构建依赖可能需要网络。完整回归在维护者本地继续执行。

## 已覆盖的行为

- 工具参数错误可反馈修正；路径越界、敏感文件、符号链接和无依据覆盖会被拒绝。
- 生成候选需有当前版本的静态检查；优化需读取 baseline 并核对可识别的计算契约。
- GPU 缺失时零模型请求地提问，补充型号后保留原任务；会话隔离与显式清空生效。
- 知识包可在原源码缺失时读取；损坏索引、分页、引用及后端过滤有本地回归。
- TUI 覆盖命令联想、中文匹配、键盘/鼠标补全、窄窗口、多行粘贴、后台调用和退出保存；真实 POSIX 伪终端与 localhost HTTP 测试验证了入口和客户端连接。
